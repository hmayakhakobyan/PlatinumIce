## Legend

- **Element ID** — the Elementor element's internal `id` inside `_elementor_data` (7-character hex string).
- **CSS Class** — the class name set on that element (shown here without regard to which settings key stores it). **Storage key differs by element type:** containers store this under `css_classes`; every widget (heading, text-editor, button, image) stores it under `_css_classes` (leading underscore) — using the wrong key silently fails to render, with no error. Always the most reliable way to locate an element by intent rather than by ID.
- **Content Type** — Heading text / Body text / Button label / Image widget (native Elementor `image` widget — Signature/Custom/Hospitality/Events/Craft) / Image placeholder label (Shop only — still a container-background text label, not yet converted) / Background (Hero only — the one section that intentionally stays a CSS/Elementor background image, not an `<img>`).
- **Current Placeholder Text** — exact text currently rendered.
